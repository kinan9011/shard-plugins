# Changelog

## 1.0.0

- Read and fill AcroForm text, checkbox, dropdown, list and radio fields, including required/read-only states.
- Preview generated appearances with PDF.js and jump between field controls and page positions.
- Import JSON/CSV mappings, preview batch rows and export independent PDFs in a ZIP.
- Save editable PDFs by default; deliberately flatten a copy with signature warnings and widget cleanup.
- Process locally in sandbox-compatible classic workers with bounded inputs and cancellable generation.
- Follow Shard theme, locale and visibility events; support responsive layouts, keyboard saves, German and Arabic RTL.
